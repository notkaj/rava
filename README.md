# rava

A rust version of cava.

This is a [Ratatui] app generated by a template.

[Ratatui]: https://ratatui.rs

## Roadmap

 - COMPATIBILITY!! (even within pipewire)
 - Better filters
 - Horizontal mode
 - Stereo mode
 - Either come up with a good reason to include async, or remove it
 - Efficiency
 - Config file / args
 - Better README file
 - Dynamic scaling for terminal height/width changes
